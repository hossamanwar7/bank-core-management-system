# 🏦 Bank Management System

A **Java-based Bank Management System** designed to simulate the core operations of a real banking environment.

The project is currently under **continuous development**, with the goal of evolving it into a more complete and realistic banking system by adding database integration, improving the architecture, and introducing additional banking features over time.

## 📌 Project Overview

The system is designed as an **internal banking management system** that allows bank employees to manage and monitor different banking operations through a structured application.

The current system focuses on applying **Object-Oriented Programming (OOP)** principles and building a scalable foundation that can be extended with more advanced technologies in the future.

## ✨ Current Features

* 👤 Customer Management
* 💳 Account Management

## 🗄️ Database Integration

Database integration is currently being developed.

The goal is to move the system from relying mainly on in-memory data to using a real relational database for persistent data storage.

Future database-related improvements include:
